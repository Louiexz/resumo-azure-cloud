# resumo-azure-cloud
Repositório do lab "Microsoft Azure - Localizando Serviços por Categoria" da Digital Innovation One.

## Tipos de nuvens

- Pública: acessada através da internet, não alocada fisicamente na empresa.
- Privada: alocada fisicamente na empresa, não disponível para terceiros fora de uma empresa.
- Híbrida: uso tanto de nuvem pública quanto privada.

## Nuvem pública

### Vantagens

- Alta disponibilidade
- Pague pelo uso
- Maior controle de custos (contanto que conheça os valores)

### Desvantagens

- Necessita profissionais especializados
- Informações fora da empresa
- Menos controle do sistema

## Azure

- A azure oferece diferentes tipos de serviços, que vai de banco de dados até virtualização de dispositivos.
- Oferecimento de serviços gratuitos + demonstrações de teste.
- É possível prever os custos, variando localidade, país, leis, taxas e outras variantes.
- Capacidade de ligar ou desligar recursos quando não estiver utilizando-os.
